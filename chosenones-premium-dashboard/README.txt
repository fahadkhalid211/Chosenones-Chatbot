Comprehensive, senior-friendly member dashboard for ChosenOnes.Faith with Paid Memberships Pro, Tutor LMS / LearnDash progress tracking, and Video Search integration.

== DESCRIPTION ==

The ChosenOnes.Faith Member Dashboard provides an intuitive, high-contrast, beautiful portal designed specifically for spiritual seekers and seniors (ages 45-75).

Features:
* Direct integration with Paid Memberships Pro (detects Active Premium Subscribers, Free Explorer members, Expired members, and Canceled subscriptions).
* Real-time course progress tracking for Tutor LMS and LearnDash with direct lesson resume links.
* Video Search Chat integration: displays 1 free search/day for Free members, 10 searches/day for Premium members, with up to 3 video recommendations per search.
* Live 24-hour countdown timer showing the exact time until daily searches refresh.
* Fast links to Community Circles, Exclusive Interviews with Ralph Amato, Live Event Gatherings, Saved Videos, and Account Billing.
* Built-in Admin QA Switcher for instant previewing of Free, Premium, Expired, and Canceled member views without having to re-login.
* Optimized for WPCode (can be pasted directly into WPCode Snippets as a PHP snippet).

== INSTALLATION OPTIONS ==

OPTION A: USE IN WPCODE (RECOMMENDED)
1. In your WordPress Admin, go to Code Snippets > + Add Snippet.
2. Choose "Add Your Custom Code (New Snippet)".
3. Set Code Type to "PHP Snippet".
4. Copy the entire contents of wpcode-chosenones-dashboard.php and paste it into the code editor.
5. Set Insertion method to "Auto Insert" (Location: "Run Everywhere").
6. Toggle status to "Active" and click "Save Snippet".
7. Create or edit a page (e.g. /dashboard/) and add the shortcode [chosenones_dashboard].

OPTION B: INSTALL AS A WORDPRESS PLUGIN
1. Upload the chosenones-premium-dashboard.zip via WordPress Admin > Plugins > Add New > Upload Plugin.
2. Activate the plugin.
3. Configure your URLs in Settings > ChosenOnes Dashboard.
4. Add the shortcode [chosenones_dashboard] to your dashboard page.

== ADMIN QA TESTING ==
Site administrators can test all membership views by simply clicking the QA Switcher pills at the top of the dashboard page:
- Actual Account
- Premium Member
- Free Member
- Expired Member
- Canceled Member
