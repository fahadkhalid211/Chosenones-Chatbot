=== Video Search Chat ===
A full-page, AI-style semantic search chatbot for a video library hosted on
Google Drive. Search happens entirely in the visitor's browser — free,
no API keys, no per-search costs.

== Installation ==

1. First, run the pipeline (see ../pipeline/README.md) to generate a real
   `data.json` from your 675 videos. This is a one-time process you run on
   your own computer, not on WordPress.

2. Replace the placeholder `assets/data.json` in this folder with the real
   one generated by the pipeline.

3. Zip this `video-search-chat` folder.

4. In WordPress: Plugins -> Add New -> Upload Plugin -> choose the zip ->
   Install Now -> Activate.

   (Alternatively, upload the unzipped folder directly into
   /wp-content/plugins/ via FTP or your host's file manager.)

5. Create or edit any page, and add this shortcode wherever you want the
   chatbot to appear:

   [video_search_chat]

   Optional attributes:
   [video_search_chat placeholder="Search by topic..." results="8"]

   - placeholder: text shown in the empty search box
   - results: how many video matches to show per search (default 6)

6. For a true "full page" feel, use a blank/no-sidebar page template and
   place the shortcode as the only content on the page.

== Updating the video data later ==

Whenever you add new videos to the Drive folder:
1. Re-run the pipeline script (it skips already-processed videos)
2. Replace assets/data.json with the updated file
3. No plugin re-activation needed — changes apply on next page load

== Data schema (for reference) ==

assets/data.json is a JSON array, one object per video:

[
  {
    "id": "1AbCdEfGhIjKlMnOpQrStUvWxYz",   // Google Drive file ID
    "driveFilename": "8294710294.mp4",      // original random filename
    "title": "How faith carries us through difficult seasons...", // auto-generated from transcript
    "excerpt": "First ~220 characters of the transcript...",
    "embedding": [0.0123, -0.0456, ...]     // 384 numbers from the embedding model
  }
]
